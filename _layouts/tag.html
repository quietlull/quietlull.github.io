--- layout: default refactor: true --- {% include lang.html %} {% comment %} A tag page. Ported to the redesign 2026-08-31; before that it was byte-identical stock Chirpy (docs/THEME-BOUNDARY-AUDIT.md), which drew a Font Awesome tag icon, a dotted `.dash` leader and a Bootstrap flex row per post. This is the layout behind 19 of the 53 built pages, so it was the largest block of unported markup left on the site. IT IS BUILT AS RAMBLINGS, on purpose and with nothing new designed. A tag page IS a filtered list of posts, which is what ramblings already is, so the same three components do the whole page: page-title-desc for the head, entry-row for the list, empty-state for a tag with nothing in it. Keeping the two pages structurally identical is the point - it is what makes a tag page look like this site instead of like Chirpy. `layout: default` RATHER THAN `layout: page`, which is what every ported layout does. The old chain went tag -> page -> default and page.html only added `
`, a Bootstrap class that D48 is removing anyway. jekyll-archives supplies both variables used below: `page.title` is the tag itself and `page.posts` is its post list (_config.yml, the `jekyll-archives` block). NO SEARCH FIELD, unlike ramblings. The list is already filtered to one tag, so the field would filter a filter, and it would cost a script include on 19 pages. NO THUMBNAIL COLUMN either, unlike ramblings, and that IS a difference worth naming: the tag pages are a lookup surface reached from a chip, so the rows stay dense. `er-row--media` is one class away if Rod wants the pictures back. {% endcomment %} {% assign posts = page.posts %}

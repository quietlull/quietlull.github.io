04 . post

Half a Million Blades of Grass

Mar 20269 min readShaders
TL;DRA GPU-instanced grass system: per-blade compute, wind via flow noise, and LOD that holds framerate.

The naive approach is a mesh per blade. That dies at a few thousand. Move the whole simulation onto the GPU.

The compute pass

Each blade is a point in a buffer. A compute shader displaces it by a wind field. Draw with DrawProceduralIndirect.

  • Spatial hash for the wind lookup
  • One indirect draw for the whole field
  • LOD by distance, not by count
The GPU doesn't care how many blades there are, only how many it can't see.
copy[numthreads(64,1,1)]
void CSMain(uint3 id) { blades[id.x].pos += windField(...) * dt; }
TakeawayStop counting blades. Count what the GPU can see, and let the rest be free.

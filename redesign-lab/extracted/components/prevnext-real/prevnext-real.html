THE PICK WAS RECORDED AND THEN NEVER BUILT. component-review says of the three text versions: "NONE OF THESE THREE. The pick is a NEW V4 - two .rc--v2 cards in a 2-lane layout, reusing the approved card." The CSS for it (.pn--cards) was written; the markup never was, in any file in the repo. So the decision existed for a day with nothing to look at. Rod 2026-08-24: "build out all the remaining components except the trophy case."

Nothing is invented here. The two lanes, the kicker above each card, the outward text alignment and the Newer/Older labelling are all specified by prevnext-real.css. The card is .rc.rc--v2, the component Rod already approved one section up in the same review — reusing it is the whole point of the V4.

WHAT CARRIES OVER FROM THE SOURCE: the outward alignment, the kicker recipe (0.8em / opacity .8 / uppercase), Newer and Older rather than Prev and Next, and the asymmetric 1.5em / 2.5em block margins. Those are still theirs, verbatim.

KNOWN, AND NOT HIDDEN: the blockout reserves 345 x 44 for each side, drawn for the TEXT version. A card is taller by construction, so this version does not fit that reservation and cannot. The reservation describes a different device. Measured height is printed under the stage so the overshoot is a number rather than a surprise.

Callout family

3 versions of the BOX · the tape is already decided · brief: analysis/reference-briefs/callout-family-the-box-under-the-tape.md
The stated source does not cover this component, and that is stated rather than papered over. gneiss supplies the TAPE, and all six of its stylesheets return zero hits for callout|notice|warning|admonition|aside. It has no callout system. So the box comes from four other sites already in sources/, each named per version below.

The tape is the differentiator, which is why the strongest box answer is the one that differs LEAST between categories. A box that also differentiated would say the same thing twice.

Every category is drawn in every version so you can see a RUN of them. That is the thing a single card cannot show, and it is what killed the last callout round.

Version 1 · one shell, the variant changes one thing

flamedfury.com — z2Ai70SrDv.css, re-fetched and byte-matched. Tier: Remixed, idea-origin theirs.
Their aside is ONE box; the role class changes only the icon. Square is a transcription, not a deviation — their border-radius: var(--border-radius) references a token defined zero times in their file, so their aside renders square too. Shadow is gneiss .pinned-note's hard 3px offset, zero blur — a blurred shadow smears the live scene, a hard one does not.

My implementation draws from research into techniques dating back to GPU Gems (2004) while incorporating 22 years of community experimentation on top of that foundation.

TL;DR

A script bakes blade positions into a buffer, one compute pass builds the geometry, and a single indirect draw renders every blade at once regardless of count.

Each frame the compute shader reads that position buffer and generates the grass blade geometry, feeding it into a vertex buffer.

Warning

Smooth the return of the grass in the shader. Without it the blades twitch every time an interactor leaves, and it looks like a physics bug rather than a missing lerp.

A top-down orthographic camera renders any interactor objects into a render texture used to control interaction, creation, and culling of the grass blades.

Note

Originally I used a ping-pong to decay the render texture, but that did not give me the control I wanted, so I went with this method instead.

Version 2 · the quiet secondary rail

catlikecoding.com — tutorials.css line 236, re-fetched. Tier: Remixed, idea-origin theirs.
The idea worth having: the box is one notch SMALLER than prose (14px against 16px), so a run of callouts reads as a quiet secondary rail rather than a stack of banners. Their heading gets no size hierarchy at all. Already square, 2px flat border, no radius, no shadow. Their disclosure behaviour is NOT taken — a callout that hides its own content is a different device from the one you decided.

Version 3 · the tape's actual partner box

gneiss.place — box.css .box + .polaroid, re-fetched. Tier: Remixed, idea-origin theirs.
This is the box the tape was designed against. gneiss's own taped markup is class="taped polaroid", so the tape's real partner is not an evenly padded card — it is the polaroid, whose deep bottom sill (padding: 1rem 1rem 3rem) is the device. That asymmetry is theirs and free, and it gives the bottom corner tapes somewhere to sit.
The trade: the warm shadow 0 3px 5px rgba(88,70,48,.5) is their real value, but it BLURS — which smears the scene. V1 and V3 are deliberately opposite on exactly this point.

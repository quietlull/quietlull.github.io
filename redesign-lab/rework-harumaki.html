Half a Million Blades of Grass

Mar 20269 min readShaders
TL;DRA GPU-instanced grass system: per-blade compute, wind via flow noise, and LOD.

The naive approach is a mesh per blade. Move the simulation onto the GPU.

The compute pass

Each blade is a point; a compute shader displaces it by a wind field. Draw with DrawProceduralIndirect.

  • Spatial hash for wind
  • One indirect draw
  • LOD by distance
The GPU doesn't care how many blades there are, only how many it can't see.
copy[numthreads(64,1,1)]
void CSMain(uint3 id) { ... }
TakeawayStop counting blades. Count what the GPU can see.

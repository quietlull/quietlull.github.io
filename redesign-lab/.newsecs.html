Rod 2026-08-23: "show the headers with color as well so there is a default color hierarchy as well." Measured first, and the answer is that colour currently tracks nothing. Three more contradictions on top of the five above, all measured:

A hazard worth knowing before you pick: --color-muted is #9aa3bd, which is a blue grey. It is the last blue left in any text token, and the palette law puts blue only in the sky. Do not reach for it as the bottom of a colour ramp — if a ramp needs a quiet step, it needs a warm one that does not exist yet.

C · L-shaped corners — two strips crossing
Tape: gneiss (CONFIRMED). L geometry: miroirs, corner positions kept. Composition: OURS
Each L is two strips overlapping the way real tape does, arms clamped clamp(44px, 60%/22%, 84px) off the card so they track any size. The two arms take different percentages on purpose — a callout is far wider than tall (625×76), so one shared percentage cannot serve both. The vertical arm sits on top, your call 2026-08-23, set as an explicit z-index rather than by reordering the markup.

The instance count is set once, at bake time. Changing it at runtime needs the buffer reallocated.

Loudest of the four — four strips per callout. Fine on a rare block, heavy if the callout repeats through a post.
D · four diagonal corner tabs — your green-card ask
Tape: gneiss (CONFIRMED). Diagonal placement: OURS — your call 2026-08-23, "for the green one the tape should have 4 diagonal strips on each corner"
One strip laid across each corner at 45°, the way tape holds a photo down. The angle is not a preference: a strip across the top-left joins the top edge to the left edge, which is a "/" — so (tl, br) run at -45° and (tr, bl) at +45°. Length is 2.6× the roll width, because a 45° rotation needs ~1.41× the diagonal reach and anything under ~2× leaves the corner poking out past the tape.

Do not read from a RWStructuredBuffer you are also writing to in the same pass. It compiles.

Reads most like a physical thing stuck down and least like a UI border. Also the only one needing no edge to attach to, so it survives on a card with no visible box.

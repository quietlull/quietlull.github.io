Row 3 · what you give up — single-path, gold, draw-in survives

The same three tools as single-path Simple Icons marks, stroked in our gold. This version keeps the pathLength="1" draw-in and obeys the palette law, and it throws away the brand colour that makes row 1 readable at a glance. These actually draw in - pathLength="1" plus an animated dash offset, staggered 0.09s apart. That one attribute renormalises every path to length 1, so ONE animation drives nine different marks with no per-icon measurement. Hit replay to watch it again. prefers-reduced-motion skips the draw and shows the finished outline.

There is no C# here because Simple Icons carries no C# mark, which is what forced the original choice.

The set in DEEP GOLD · --color-gold-deep #f59e0b

All nine marks, tinted with a CSS mask rather than by editing the sourced files - the mark becomes the mask and the colour sits behind it, so the file on disk stays exactly as downloaded and its citation stays true.

This also solves the contrast problem outright. Measured against the night ground, Unreal's own #0E1128 is 1.04:1, which is invisible, and the devicon Unity, Blender and Vulkan all sit at 2.2-2.6:1. Masked, no brand colour reaches the page at all and every mark reads the same.

Includes your four picks - Python, Unreal, Godot, Maya - plus Unity, Blender and Git already held, and OpenGL / Vulkan as Compute candidates. No C#: Simple Icons carries none, verified against their 3,453-icon index.

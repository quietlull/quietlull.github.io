## The one rule everything was built against

**The site had to still render at every step.** You review in the morning, and a half-ported site
that looks broken is worse than a smaller merge that works, because a broken one cannot be judged.

left on disk rather than deleted, and nothing in the gitignored lab is `rm`'d - it is moved to a
holding directory you can approve or reverse in one command.

## Measured, and it made the job smaller than the docs implied

- The old site defines **303** custom properties and **never references 117 of them**.
- Of the 186 that are used, the heaviest consumer is `vendors/_bootstrap.scss` at **167** - PurgeCSS
  output, regenerated by `npm run build`, never hand-edited. It is not a hazard, it is a rebuild.
- The next heaviest are the old design's own layout partials, which D42 declares dead. They do not
  need repointing; they need deleting, later.
- **Only two names ever overlapped between the two token sets** - `--z-content` and `--z-overlay`,
  both z-index plumbing, neither a colour. There was no shared vocabulary to preserve.

So the feared "deleting live tokens shatters Chirpy" is mostly not real. The genuinely hand-written
surface that needs care is `_base.scss` and `_mixins.scss`.
